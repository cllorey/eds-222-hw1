# EDS 222 HW 1

## Get started

Begin by cloning this repo to your directory on Workbench. Make sure to complete all the exercises on Workbench - that's what we'll use for grading and feedback. 

## Part 1: Inference

Demonstrate your understanding of statistical inference tools by completing the exercises in `inference.qmd`.

The rubric by which your work will be assessed is in `inference-rubric.md`.

Please note: some details are deliberately unspecified. For example, you will be estimating a confidence interval, but the confidence level is unspecified. Use your judgement to make appropriate choices for these details.

## Part 2: Exploratory Data Analysis

Begin thinking about your final project! `eda.md` contains a series of prompts to get you started thinking about questions and data. You'll download real data and begin exploring it in a new Quarto document.
