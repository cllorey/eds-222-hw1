# Rubric for the _inference_ exercises

## 1. Conduct a permutation test

 - [ ] All necessary code is included in the Quarto document
 - [ ] The null and alternate hypotheses are correctly stated
 - [ ] The code correctly conducts a permutation test
 - [ ] The raw data are visualized appropriately
    - [ ] The two groups are distinctly discernible in the visualization
 - [ ] The null distribution is visualized appropriately
    - [ ] The observed statistic is indicated on the null distribution
    - [ ] The part of the null distribution corresponding to the p-value is indicated
- [ ] The p-value is _calculated_ properly
- [ ] The p-value is _interpreted_ properly

## 2. Estimate a confidence interval

 - [ ] All necessary code is included in the Quarto document
 - [ ] The code correctly estimates a confidence interval
 - [ ] The raw data are visualized appropriately
    - [ ] The two groups are distinctly discernible in the visualization
 - [ ] The sampling distribution is visualized appropriately
    - [ ] The observed statistic is indicated on the null distribution
    - [ ] The upper and lower bounds of the confidence interval are indicated
- [ ] The confidence interval is _calculated_ properly
- [ ] The confidence interval is _interpreted_ properly

## 3. Simulate a negative result

 - [ ] All necessary code is included in the Quarto document
 - [ ] The code correctly simulates a negative result
 - [ ] The PDF describing the population is visualized appropriately
 - [ ] The p-values for each simulation are calculated correctly
 - [ ] The distribution of p-values is visualized appropriately
    - [ ] The p-values corresponding to _false positives_ are indicated
